## 排查:go-oswbb 远程 Web 无法访问 (root@192.168.56.215:3001)

**现象**:用户在该机器上运行 `/opt/oswbb/go-oswbb -archive /opt/oswbb/archive/`,但浏览器打不开 `http://192.168.56.215:3001/`。

**代码层结论**:
- `main.go` 用 `http.ListenAndServe(":3001")`,监听所有网卡(=0.0.0.0:3001),端口默认 3001,`-archive` 不改端口也不关 Web。绑定地址不是问题。
- **隐藏缺陷(已修)**:`-archive` 启动只记录归档路径,**不导入 SQLite**。前端首页"是否有数据"取决于 DB(`/api/statistics`),DB 为空 → 侧边栏图表入口全隐藏,页面看起来"看不到数据"。图表 API 虽能直接读归档目录,但 UI 入口被 DB 数据门控。

**改动**:
- `internal/web/handlers.go`:新增 `Server.ImportConfiguredArchive()`,启动时按 `-archive` 配置自动 `FindArchivePath` 解析真实归档根并导入 SQLite(`DropAllTables` + `importArchiveData` + 清缓存)。
- `main.go`:创建 server 后调用 `srv.ImportConfiguredArchive()`;并把启动日志从 `localhost` 改为明确提示监听 `0.0.0.0:<port>`、需防火墙放行。
- 已 `go build ./...` 通过。

**仍需用户在服务器侧排查(网络/防火墙,我无法触达 192.168.56.215)**:
- `ps aux|grep go-oswbb` / `ss -tlnp|grep 3001` 确认进程在且监听 0.0.0.0:3001
- 本机自测 `curl -I http://127.0.0.1:3001/` 成功 = 程序健康,问题在外部
- 防火墙:`firewall-cmd --list-all` / `iptables -L -n` / `ufw status`,放行 3001/tcp
- 192.168.56.x 是 VirtualBox host-only 网段,从非宿主机跨网访问不可达,需桥接或端口转发
- 用 `nohup ... &`/systemd 保证进程不因 SSH 断开退出

**验证**:重建后带 `-archive` 运行,`curl http://127.0.0.1:3001/api/statistics` 应返回 `hasData:true`。

## 新增:归档模式页面刷新(手动 + 每30秒自动)

**需求**:`-archive` 启动时,页面可手动刷新,也可开启每 30 秒自动刷新(对应 OSWatcher 持续写入 .dat 的场景)。

**实现**:
- `internal/web/handlers.go`:新增 `POST /api/refresh`(`handleRefresh`),复用 `ImportConfiguredArchive()` 重新解析归档根、清空旧表、重新导入、清图表缓存;未配置 `-archive` 时返回 400。
- `internal/web/server.go`:路由注册 `POST /api/refresh`。
- `web/templates/layout.html`:主内容顶部加 `#archiveRefreshBar`(含"归档模式"徽标、归档目录、手动刷新按钮、每30秒自动刷新勾选框、状态提示),默认 `display:none`。
- `web/static/js/app.js`:`initArchiveRefresh()` —— 启动拉 `/api/archive-path`,有路径才显示工具条;手动刷新 `POST /api/refresh` 后 `location.reload()` 全页刷新;自动刷新勾选后 `setInterval(30s)` 并写入 `localStorage('oswbb_auto_refresh')`,reload 后自动恢复(否则勾选状态会随 reload 丢失)。
- `web/static/css/style.css`:`.archive-refresh-bar` 吸顶样式。

**验证**:本地用假归档(oswvmstat/sample.dat)冒烟测试,`/api/archive-path`/`POST /api/refresh`/`/api/statistics`(hasData:true)/`GET /`(200) 全部通过;已 `go build ./...`。
**注意**:30秒自动刷新采取整页 reload 方式(简单可靠),会重置查看器页的交互状态;若日后需"软刷新不重载",需给 viewer.js/index 暴露全局重渲染钩子。
